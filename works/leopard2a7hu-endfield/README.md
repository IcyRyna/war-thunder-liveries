# Leopard 2A7HU ENDFIELD

当前版本：[v4](https://github.com/IcyRyna/war-thunder-liveries/releases/tag/works/leopard2a7hu-endfield/v4)（2026-10-20）。状态：**待评价**。

基于 [HK416の午夜福音的 Leopard 2A7V ENDFIELD 原作](https://live.warthunder.com/post/1162771/en/) 适配。车体和炮管保留作者原纹理；HU 专属炮塔、附加件和遥控武器站沿黑白黄画风制作。原作备份见 [参考作品](../../references/leopard2a7v-endfield/README.md)。

![七视图](preview.png)

本版修复炮塔前斜装甲的三角形错贴：旧 UV 转移跨过来源接缝，把无关的白圈、暗块和边缘花纹拉到装甲上。现在按真实表面逐纹素对应，仅重做左右两组共同前装甲，并保护其他构件占用的 UV 及零面积 UV 取样足迹。

仅炮塔颜色 DDS 和法线 DDS 改变，其余 13 张 DDS 与 v3 逐字节一致。已修复的顶盖与武器站保持。本版 15 张 DDS、BLK、像素往返及部署哈希检查通过；七视图和局部对比读取实际游戏包 DDS。可编辑工程包含修补脚本、原生 UV 模型、素材、参数和当前贴图。

已部署至 `War Thunder/UserSkins/Leopard2A7HU_ENDFIELD_v4`，仍待用户游戏内评价。离线渲染使用静态模型和近似光照。
