# EMBT（法国）· ENDFIELD

面向 EMBT 实际 UV 的终末地工业风涂装。保留已核实共用的 A7V 车体图集编排并改为 EMBT / FR 铭牌，炮塔、炮管与专属附加装甲重新设计。

版本：[v1](https://github.com/IcyRyna/war-thunder-liveries/releases/tag/works/embt-endfield/v1) · 状态：待评价

原作参考与共用车体编排：[HK416の午夜福音 · Leopard 2A7V ENDFIELD](https://live.warthunder.com/post/1162771/en/)。终末地官方图形版权归原权利人；[参考资料](../../../references/ground/leopard2a7v-endfield/README.md)。

![七视图](preview.png)

深色顶盖、灰白装甲面、侧向黄色路线与主次字标按低平炮塔安排。原生结构法线和 AO 保留，储物网格单独配色并保持透明裁切轮廓。七视图、豹子对照与炮塔近景均来自最终 DDS 的离线模型，实机观感与用户美术评价待确认。
