## 安装与工程

游戏包解压后，将含有 `.blk` 和纹理的整个作品文件夹放入对应客户端的 `UserSkins/`。

适配德国与法国 EMBT，分别使用 `germ_embt.blk` 和 `fr_embt.blk`。当前工程含 52 份 CMPS、整幅贴图、模型与独立重建工具。

从工程根目录运行 `python -B -X utf8 design/当前工程/build_skin.py --check` 可检查源文件与游戏贴图；图层索引见 `design/当前工程/editor-index.json`。游戏内视觉复检未运行，展示图使用真实模型与当前贴图的离线渲染。
