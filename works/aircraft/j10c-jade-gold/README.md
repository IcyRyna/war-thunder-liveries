## 安装

将 ZIP 中的 `J10C_Si` 文件夹解压到游戏的 `UserSkins`，进入对应载具的自定义界面，刷新后选择同名涂装。

青玉金黄无人物版和祀人物版使用同一个包内目录。想要并存时，可在解压时给其中一套涂装文件夹另取名字。
