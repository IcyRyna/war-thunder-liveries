## 约定

- 目录：`works/<作品>/` 放我们的作品，`references/<作品>/` 放参考作品；每个目录有 `README.md` 和 `preview.png`。
- 标签：我们的作品 `works/<作品>/v<版本>`，参考作品 `references/<作品>/<来源编号>`。
- 状态：已认可、待评价、已否定，以用户评价为准。
- 大文件（zip、tga、dds、cmps）只进 Release，不进 Git 历史。
