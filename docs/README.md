## 状态怎么理解

| 状态 | 含义 |
| --- | --- |
| 已认可 | 该作品的当前美术方案已有明确认可，具体范围见作品页 |
| 部分认可 | 有明确认可的局部，整套仍有需要修订或评价的部分 |
| 初步成果 | 已提供可用文件，仍保留继续制作和修订的空间 |
| 待评价 | 已有作品与文件，尚未形成完整评价 |
| 已否定 | 历史方案，保留用于对照和追溯 |
| 参考原作 | 其他作者的作品，作者、来源和使用范围单独记录 |

## 常见术语

| 名称 | 中文解读 |
| --- | --- |
| UV | 把三维车体或机体表面展开到二维贴图的位置关系 |
| DDS／TGA | 游戏读取的纹理文件格式 |
| BLK | 指定载具贴图替换关系的配置文件 |
| CMPS | Composa 的原生分层工程，用来继续编辑图层 |
| 七视图 | 将多个主要方向汇总到一张展示图中 |
| Release／Assets | GitHub 的发布页和其中可下载的附件列表 |
| SHA-256 | 文件指纹，用于核对下载前后内容是否一致 |
