# 仓库维护

## 目录与文件

| 内容 | 位置 |
| --- | --- |
| 飞机和地面载具作品 | `works/aircraft/`、`works/ground/` |
| 参考原作 | `references/`，保留作者和来源 |

| 文件校验 | `docs/checksums/` |

游戏包、分层工程和大型图片放入 Release。作品页、首页、下载索引和校验记录应对应同一份公开文件。

## 作品评价

“已认可”“部分认可”“待评价”等状态来自实际评价，具体认可范围和已知问题在作品页保留。目录整理、技术检查和文件上传不改变作品评价。

每件作品独立维护版本线，使用固定版本标签保存历史，`current` 作为当前下载入口。新作品或内容修订发布前，应确认具体预览、文件清单与允许发布的范围。

## 公开资料

公开页面保留使用说明、评价结论、来源与必要技术资料。内部逐句对话、本机绝对路径和环境记录留在本地维护资料中。

下载校验值以原发布页为准；当前整理范围见[仓库内容与下载说明](distribution.md)。素材的使用范围见[许可说明](licensing.md)。
