# 安装涂装

在作品页下载 TGA 或 DDS 游戏包。若同时提供两种格式，选一种即可。

解压后，将包含 `.blk` 和纹理文件的整个涂装文件夹放入游戏目录的 `UserSkins/`：

```text
War Thunder/
└── UserSkins/
    └── 涂装文件夹/
        ├── 载具.blk
        └── 纹理文件
```

在机库中选择对应载具，再从涂装列表中选用。找不到涂装时，先检查是否多嵌套了一层文件夹，以及是否选中了对应车型。

设计源包用于修改图层、图形和制作参数；`.cmps` 文件用 Composa 打开。展示图包保存预览和拼版文件。各类下载在作品页分别标注。

游戏涂装包不附带 `CREDITS.txt` 和 `SHA256SUMS.txt`。作者与素材来源见作品页及[素材来源](credits.md)，下载校验值保留在仓库的 `docs/checksums/` 和 Release 说明中。
