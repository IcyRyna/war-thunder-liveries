# 安装与继续编辑

## 安装游戏涂装

1. 在[作品集](../README.md)选择对应机型或车型，进入作品页。
2. 下载标注为“游戏涂装”的 ZIP，将其解压。
3. 把整个涂装文件夹放入所用客户端的 `UserSkins/`。
4. 进入机库，在对应载具的自定义涂装列表中刷新并选中它。

目录应类似：

```text
UserSkins/
└── 作品文件夹/
    ├── 载具配置.blk
    ├── 颜色纹理.dds
    └── 其他配套纹理.dds
```

TGA 作品使用相应的 `.tga` 文件。配置和纹理保留包内原名称。

## 游戏里找不到涂装

| 检查项 | 处理方式 |
| --- | --- |
| 多解压了一层目录 | 打开作品文件夹，确认能直接看到 `.blk` 和纹理 |
| 放进了另一份客户端 | 确认 `UserSkins/` 属于实际启动的客户端 |
| 载具不匹配 | 按作品页说明选择对应车型，留意德国／法国等差异 |
| 文件未下载完整 | 按[校验说明](downloads.md#校验下载)核对 SHA-256 |

## 继续编辑

下载作品页的可编辑源码 ZIP，先阅读包内 README。CMPS 是 Composa 分层工程；脚本与配置按包内说明使用。内部目录和原始修订文件名保留，便于继续制作。
