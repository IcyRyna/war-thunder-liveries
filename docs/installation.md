# 安装涂装

在作品页下载游戏涂装 ZIP，解压后把整个涂装文件夹放入对应客户端的 `UserSkins/`。
文件夹内应直接包含载具 `.blk` 和配套 DDS/TGA 纹理，避免多嵌套一层目录。
进入机库选择对应车型，在自定义涂装列表里刷新并选择该文件夹。

可编辑工程与源码另行下载；保留的原工程文件名不作为公开制作版本标签。
七视图和三张宣传大图是独立图片附件，游戏 ZIP 不收录宣传图。
来源说明与下载校验留在作品页和仓库，不再随游戏包附带 CREDITS.txt 或 SHA256SUMS.txt。

GitHub 自动生成的 Source code ZIP/TAR.GZ 是当前标签对应的展示仓库快照；它不等于可编辑图层工程。需要编辑时，请选择作品页的源码 ZIP。
