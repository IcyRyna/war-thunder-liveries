# 下载文件说明

## 游戏包

游戏涂装 ZIP 保存 `.blk` 配置和配套纹理。下载后按[安装指南](installation.md)解压到 `UserSkins/`，游戏无需读取分层工程。

作品页会分别列出 DDS、TGA 或不同车型的版本。以实际车型和文件清单为准。

## 可编辑工程

源码 ZIP 保存当前可提供的设计资料，可能包含 CMPS、图层素材、模型、配置和重建脚本。每件作品的完整程度不同；没有原生工程的作品会在说明中写明。

解压后先阅读包内 README，再打开工程。保留内部目录与原有文件名，可以维持图层引用和脚本关系。需要外部工具的配置使用可移植位置或按说明填写。

## 展示图

七视图用于看整体布局；独立整车大图用于看主要角度。展示图单独下载，游戏包只保存运行所需文件。

## GitHub 的 Source code 是什么

Release 页面底部自动生成的 **Source code (zip)** 和 **Source code (tar.gz)** 是展示仓库的源码快照。需要制作工程时，请选择作品页明确标注的“可编辑工程与源码”附件。

## 校验下载

在[校验目录](checksums/)找到对应作品的 SHA-256。Windows 可在 PowerShell 中运行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\下载的文件.zip'
```

将结果与仓库记录比较。附件内容变更后，以当前发布页和校验目录记录的指纹为准。
