# 素材来源

## 角色与风格

角色素材的权利属于相应作品和权利人。部分方案使用了参考官方素材的生成重绘，相关作品页保留这一说明。

Akamywek 风格作品以该作者的公开涂装为风格参考。

## 终末地坦克

Leopard 2A7HU ENDFIELD 基于 HK416の午夜福音 的 [Leopard 2A7V 原作](https://live.warthunder.com/post/1162771/en/)适配。车体和炮管保留原作纹理，HU 专属构件另行适配。原作者与来源同时标在作品页和[参考目录](../references/README.md)。

## F-2A 复刻

F-2A 复刻保存 Claude r14 的学习结果。原设计为 [Akamywek 的 F-2A M4 SOPMOD II](https://live.warthunder.com/post/1169410/en/)，材质和挂载贴图沿用原作。
